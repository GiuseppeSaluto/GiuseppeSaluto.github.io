# giuseppesaluto.github.io

My personal site: who I am, what I'm building, where to find me.

Live at https://giuseppesaluto.github.io

One static page, no framework and no build step: `index.html` plus two images in `assets/`.
Colors from a Casio G-Shock Rangeman, layout inspired by [Andrea Leopardi's site](https://andrealeopardi.com/).

## Updating it

- **A project's status:** in its card, set the `status` class to `underway` (in progress), `anchored` (on hold) or `berth` (done), and change the label next to it.
- **A new project:** copy one `<li>` in the `projects` section and edit it.
- **Colors:** the variables at the top of the `<style>` block.
